# Bennett Studio — Marketing Site

The MarginPrint marketing site (by Bennett Studio). Vite + React + Tailwind + Framer Motion.

## Run

```bash
cd bennett-studio-site/site
npm install
npm run dev
```

Opens at http://localhost:5180

## Build

```bash
npm run build
```

Outputs to `dist/`.
